# House-Price-Prediction

### Project Overview



This project is a Machine Learning regression model that predicts house prices based on different features such as area, number of rooms, bathrooms, and other property attributes.



It is built using Python, Pandas, Scikit-Learn, and Jupyter Notebook.

### Objective



To build a predictive model that can estimate house prices accurately using historical housing data

### Dataset

Source: Kaggle / Public Housing Dataset

File: House Price Prediction Dataset.csv

Contains features like:

Area (sq ft)

Bedrooms

Bathrooms

Location features (if available)

Price (Target variable)
